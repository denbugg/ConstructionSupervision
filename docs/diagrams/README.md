# diagrams

Экспортированные изображения диаграмм для презентации и документации .docx/.pdf.

Источник истины — **mermaid-диаграммы внутри markdown-файлов** `docs/` и README сервисов.
Сюда кладутся только экспорты (PNG/SVG) с тем же именем, что у документа-источника,
например `architecture-context.svg`. Правим диаграмму в документе, затем переэкспортируем.

`pos-engine-legacy.png` — схема первоначального замысла отдельного сервиса нормативных
расчётов. **Не актуальна:** генератор графика стал модулем plan-service
([ADR-0011](../decisions/0011-generator-and-reports-as-modules.md)). Хранится как история.
